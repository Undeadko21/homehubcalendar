# Навык Алисы «Семья»

Отвечает на вопросы вроде «когда следующая встреча Оли», «что завтра у папы», «кто отвозит Машу».
Домашний сервер не открывается в интернет: функция читает тот же зашифрованный снимок с Яндекс.Диска,
что и приложение (см. «Настройки → Подключение → Облако»).

## Установка

1. **Облачная функция.** В [Yandex Cloud](https://console.yandex.cloud) → Cloud Functions → создать функцию
   (Python 3.12, точка входа `handler.handler`), загрузить `handler.py` и `requirements.txt`.
   Переменные окружения: `HOMEHUB_URL` и `HOMEHUB_KEY` — скопировать в «Настройки → Подключение → Облако →
   Для навыка Алисы». Сделать функцию публичной («Публичная функция» в настройках) — Алиса вызывает её без авторизации.
2. **Навык.** На [dialogs.yandex.ru](https://dialogs.yandex.ru/developer) → Создать диалог → Навык в Алисе.
   Название «Семья», бэкенд — Functions в Яндекс Облаке, выбрать функцию. Оставить черновиком: навык виден только вам
   (и тестировщикам, которых добавите во вкладке «Тестирование»). Станция должна быть привязана к этому же аккаунту.
3. **Проверка.** Во вкладке «Тестирование» написать «когда следующая встреча Оли», затем сказать станции
   «Алиса, спроси у Семьи, когда следующая встреча Оли».

## Что понимает

- «когда следующая встреча Оли / у папы» — ближайшее событие;
- «что сегодня / завтра / послезавтра у Маши» — список на день;
- «что сейчас у Олега»;
- «кто отвозит Машу» — ближайшая поездка ребёнка;
- «я Оля» — запоминает, кто говорит; после этого «когда моя следующая встреча» отвечает про неё.

Имена берутся из списка людей календаря (и слов автопривязки), падежи учитываются.

## Заметки

- Снимок обновляется раз в 2 минуты и охватывает 7 дней: дальше навык говорит «ближайшие дни встреч нет».
- Ключ расшифровки хранится в переменных функции; кто получит доступ к облачному аккаунту, сможет читать расписание.
- Тесты: `python -m pytest alice`.

## Настройки функции

Таймаут функции — **не меньше 5 секунд** (при 1 секунде холодный старт не успевает загрузить снимок и Алиса
получает ошибку 500), память — **256–512 МБ** (быстрее старт). Алиса сама ждёт ответ не дольше 3 секунд;
после первого вопроса снимок кэшируется на 2 минуты. Готовый архив: `alice/function.zip` (загрузить в «Редактор → ZIP-архив»).
