# HomeHub Calendar

Домашний календарь для всей семьи: собирает события из Яндекс.Календаря
(и любых CalDAV/ICS-источников) и показывает их в одном веб-интерфейсе —
на телефонах, компьютерах и на экране на стене.

Сейчас работает в режиме **только чтение**: ничего не меняет в исходных календарях.

## Что умеет

- **Сегодня** — большие часы, погода, колонка дел на каждого члена семьи, что будет завтра.
- **Лента** — строка на каждого человека: видно, кто когда занят (1 день, 3 дня или неделя).
- **Неделя** и **Месяц** — классическая сетка.
- **Список** — ближайшие события по дням, удобно на телефоне.
- Фильтр по людям (нажатие — скрыть/показать, двойное — только этот человек).
- Склейка дублей: приглашение, которое лежит в календарях двоих, показывается один раз.
- Календари можно показывать как «Занят» без деталей (⚙ Настройки → «только занят»).
- Праздники, переносы и сокращённые дни по производственному календарю РФ.
- Режим экрана на стене: `/?kiosk&view=today` (ночью приглушается; `&rotate=60` — смена видов).
- Тёмная тема, установка на телефон как приложение.
- PIN-код на вход (по желанию).

## Установка на Proxmox

В консоли Proxmox (узел → Shell):

```bash
bash install-proxmox.sh
```

Скрипт лежит в `deploy/install-proxmox.sh`. Он создаст LXC-контейнер, поставит Docker,
заберёт код, спросит логин Яндекса и **пароль приложения**
([создать](https://id.yandex.ru/security/app-passwords) → «Календарь») и запустит календарь.
В конце покажет адрес.

Потом откройте календарь → ⚙ **Настройки** → укажите, чей какой календарь.

### Обновления

На сервере каждые 15 минут работает `deploy/update.sh`: если в ветке `main` появились
новые коммиты, он подтягивает их и пересобирает контейнер. Ручной запуск:

```bash
pct enter <CTID>
/opt/homehub-calendar/deploy/update.sh --force
```

Настройки (`config/`) и данные (`data/`) при обновлении не затрагиваются.

## Настройки

- `config/config.yaml` — источники, часовой пояс, погода, праздники (пример: `config.example.yaml`).
- `config/.env` — секреты: логин и пароль приложения Яндекса, PIN (пример: `.env.example`).
- Люди и привязка календарей к людям — в интерфейсе, ⚙ Настройки.

После правки файлов: `docker compose restart` в `/opt/homehub-calendar`.

## Разработка

```bash
# бэкенд
cd backend && pip install -r requirements.txt pytest
python -m pytest
python tools/make_demo.py ../demo          # демо-календари
cd .. && HOMECAL_CONFIG=demo/config.yaml HOMECAL_DATA_DIR=data PYTHONPATH=backend \
  uvicorn app.main:app --port 8765

# фронтенд (проксирует /api на :8765)
cd frontend && npm install && npm run dev
```
