# Журнал решений

Почему сделано так и от чего пользователь отказался. Читают все помощники (`architect`, `reviewer`, `executor`) — чтобы не предлагать снова
и не «исправлять» намеренное. Новое решение — в НАЧАЛО раздела, одной-двумя строками: что, почему, дата/версия.

## Отказы пользователя (не предлагать снова)
- **Масштабирование на других пользователей** (облачный сервис, открытый «поставь у себя», связной сервис, 2026-11-18): не нужно. Календарь — для одной семьи.
- **«Кто я» на устройстве** (выбор владельца телефона): не нужен; в карточке поездки нет кнопки «Я».
- **Рабочие календари одной полосой** (сворачивание в «занят»): не нужно.
- **VPN и полный доступ вне дома через VPN**: не хочет. Вне дома — снимок на Яндекс.Диске и публичный адрес `homehubcalendar.ru`
  (VPS с Caddy + обратный SSH-туннель) по PIN.

## Принятые решения
- **Правки Swift — только через pull request** (v0.20.1): сборки iPhone/Mac проходят в PR до слияния, сервер и приложения выходят вместе. `deploy/check.sh` в `main` не пускает (`HH_SWIFT_PR_OK=<PR>` — когда сборка в PR уже прошла).
- **Песочница прода обязательна для рискованных файлов** (v0.20.1): `check.sh` требует отметку `sandbox.py` для этих правок; без копии базы — только явный пропуск с причиной и упоминание в отчёте. Ключ и копия базы в сессии разработки обычно отсутствуют — это осознанно (данные семьи).
- **Шум уведомлений — в сводке дозора** (v0.20.1): пороги в `api/system.py` (`NOISE_*`); превышение — строка «Шум: …» в `problems`, только счётчики, без текстов.
- **Яндекс.Диск остаётся, хотя есть доступ через VPS** (2026-11-18): на нём снимок для Алисы, запас на случай недоступного дома (VPS — только проход домой, данных на нём нет), команды с телефона без связи с домом и ночные зашифрованные копии базы. Не предлагать убрать или заменить VPS-ом.
- **Любой пуш в `main` = прод** (автообновление раз в 15 минут). Поэтому: `deploy/check.sh`, ревью перед крупным пушем, рискованное — в ветке и pull request.
- **Репозиторий публичный** — секретов в нём нет: токены (запись Диска, VPS, виджеты, дозор), PIN, код `hhc1.` не печатаются в ответах, коммитах, логах.
- **Дозор (`/api/watch`)** видит только сводку: версия, проблемы, скорость, ошибки экранов; без календаря, списков, адресов и секретов.
  Отдельный токен `auth:watch`, другие маршруты им не открываются. (v0.15.1)
- **Календарь «только чтение» не ошибка:** самопроверка пропускает такие календари и помечает их, а не поднимает тревогу. (v0.15.2)
- **Офлайн-версия сайта** — service worker: лента читается из кэша, запись — только онлайн (очередь записи есть у приложений, не у сайта). (v0.15)
- **Поездки отдельными событиями** у взрослых — только если включено «показывать поездки»; по умолчанию видны на самом событии.
- **Swift здесь не собирается** — приложения iPhone/Mac собирает только GitHub Actions; общий код (`HomeHubCore`) проверяют Swift-тесты на снимке от настоящего сервера.
- **Проверка после выкатки ждёт до 30 минут** (таймер дома 15 мин + сборка образа). Красный `postdeploy` при недоступном доме — ожидаемо, не баг.
- **Ревью pull request** делает еженедельный ревизор (комментарий «Ревью помощника»), а не CI: ключа к модели в GitHub нет и заводить его не хотим.
