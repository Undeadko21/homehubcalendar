## Ждёт пользователя
- [2026-11-20] **Секрет `WATCH_TOKEN` в GitHub** — прокси сессии не пускает в настройки секретов. Пользователю: GitHub →
  репозиторий → Settings → Secrets and variables → Actions → New repository secret: имя `WATCH_TOKEN`, значение — токен
  «Дозор разработки» (приложение: «Связь вне дома» → «Сервер и уведомления»). Без него `postdeploy.yml` проверяет только
  открытые адреса.
- [2026-11-19] **«Маршрут» в уведомлении Android** — открываются ли Яндекс Карты с текстовым адресом (`rtext=~адрес`).
  Проверить на телефоне в следующий «Пора выезжать».
- [2026-11-20] **Уведомления в браузере на компьютере** — проверено шифрование по RFC 8291 (совпадает с `http_ece`), но не
  настоящая доставка через Chrome/Edge/Firefox/Safari. Включить в «Напоминаниях» → «Проверить».
