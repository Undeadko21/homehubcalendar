# Грабли (читать перед правкой и ревью)

Ошибки, которые уже случались или были пойманы в последний момент. Каждая — одной-двумя строками: что, как узнать, как правильно.
Наступили на новые — допишите сюда в том же коммите (новые — в начало раздела). Читают: основной Claude, `reviewer`, `executor`,
`apps-checker`, дозор и ревизор.

## Бэкенд
- **Один адрес — два маршрута** (v0.19: новый `GET /api/changes` молча перекрыл журнал записей с «отменить»). Перед новым маршрутом —
  `grep -rn '"/api/<имя>' backend/app`. Сторож: `tests/test_routes_unique.py`.
- **Дата без пояса против даты с поясом** (v0.19, блокер): событие «весь день» — `"2026-11-12"` (без пояса), `now` — с поясом;
  сравнение → `TypeError` и падение снимка. Приводить к одному виду (`eventlists._aware`), тест на событие «весь день».
- **Сигнатура подменённой функции в тестах** (v0.19): тест подменял `_compose(s, e)`, а вызов стал `_compose(s, e, track=True)` —
  ошибка в фоновом потоке проглатывалась, тест просто висел/падал по таймауту. Подмены писать с `**kw`.
- **Меняешь формат общей функции — найди всех, кто её вызывает** (v0.19: `todo_texts` → `[{id, text}]`): `grep -rn <имя> backend/app`.
- **Журнал/уведомление из сравнения состояний**: первая сборка после запуска, пустая лента до загрузки календарей, скрытие календаря,
  смена «личное» — это не изменения событий (v0.19, `_track_changes`). Иначе — ложные «Много изменений» и раскрытые названия.
- **Серия событий**: перенос серии = N вхождений сразу; сопоставлять по UID и дню, а не по точному началу (v0.19, `changes.diff`).
- **Личные события** («Занят»): прежнее название и место нигде не показывать — ни в журнале, ни в уведомлении, ни в снимке.
- **`people` пустой** = «всем» на сервере, но «никому» в приложениях (Android/iPhone/Mac фильтры) — для уведомлений всем подставлять
  список взрослых явно.
- **iPhone/Mac показывают только будущие напоминания** (`Notifier.swift`): уведомление с `at` в прошлом до них не дойдёт,
  кроме `alert`, `digest`, `chg:` (показ сразу, один раз).
- **Кэш с ключом по диапазону дат** растёт каждый день — кэшировать только широкое окно, чистить при смене окна (v0.19, `expand.py`).

- **Адрес, который присылает браузер или пользователь, и сервер по нему ходит** (подписка Web Push, v0.21) — только список
  разрешённых хостов, https, без редиректов: иначе сервер можно направить во внутреннюю сеть дома.
- **Подписка/доступ, живущие отдельно от сессии входа** (v0.21) — привязывать к сессии: «Отключить устройство» должно снимать всё.
- **Цикл отправки по списку получателей** — исключение одного не должно обрывать остальных и сбрасывать отметки «отправлено».
- **Перенос серии на другой день** — пересчитать день в RRULE (`BYDAY`), и для «по вторникам», и для «2-й вторник» (v0.21).

## Интерфейс (Vue)
- **`computed`/`ref` в скрипте без `.value`** — объект всегда «истинный» (v0.20: «Связь вне дома» в настройках всегда
  показывала «нет связи снаружи»). В шаблоне `.value` не нужен, в `<script>` — обязателен. Сторож: eslint `vue/no-ref-as-operand`.
- **`personById` — computed-объект**: в скрипте `personById.value[id]`, в шаблоне `personById[id]`; не функция.
- **Имя без импорта** (v0.19: `newEvent` в `App.vue`) — сборка проходит молча, ошибка только при нажатии. Сторож: eslint `no-undef`.
- **Повторяющийся ключ в объекте** (`api.js`: второй `changes:` затёр бы первый). Сторож: eslint `no-dupe-keys`.
- **`news.js`**: `n` строго подряд, новые — в начало; дыра в номерах ломает тест «давнему устройству».
- **Комментарий в конце элемента массива съедает запятую**, если вставлять текст заменой «до `]`» (v0.20, `icons.js`): `[a, b],   // …`.
- **Регулярки по русским словам**: `\b` не видит кириллицу — короткие слова через `w('<слово>')` в `lib/icons.js`; проверять
  ложные срабатывания («генеральная репетиция», «аналоговое», «коллегой»).

## Приложения
- **Swift собирается только в GitHub Actions** — правки `ios/`, `macos/` только через ветку и pull request (сторож: `deploy/check.sh`).
- **Android: новая кнопка в уведомлении** — уникальные `requestCode` у `PendingIntent`, id команд Outbox уникальны и при нескольких
  подряд в одну миллисекунду (v0.19: UUID).
- **Общий список, привязанный к событию** (например, «Покупки») — массовые действия «отметить всё» только для своего (`own`) списка.

## Процесс
- **Журналы GitHub Actions публичные** (репозиторий открыт): из `/api/watch` и сообщений семьи туда — только счётчики,
  никаких текстов проблем, имён и названий (`postcheck.sh` с `HH_QUIET=1`, v0.21). В PR дозора — пересказ без имён.
- **Предлагать «новое» — сначала `docs/dev/features.md`** (v0.20: «обратный отсчёт», «голосовой ввод», «вечерняя сводка»
  предложены как новые, а они уже были).
- **Рискованные файлы (лента, снимок, база, запись)** — дом проверит версию на копии базы перед подменой; после пуша убедиться,
  что версия на `/api/health` сменилась (не сменилась за ~30 мин — причина в «Состоянии»).
- **`update.sh` при выкатке меняет сам себя** (`git reset`): байты до строки `git reset` не менять (правило 3); хвост — функция
  `deploy_tail`. Новый хвост начинает работать только со СЛЕДУЮЩЕЙ выкатки — текущую доводит уже запущенный старый (v0.20.2).
  Сторож — `deploy/test-rollback.sh` (сценарий «старый скрипт → новый коммит»).
- **Процесс 1 в контейнере** не получает SIGTERM без своего обработчика: `timeout docker run …` без `--init` не останавливает (v0.20.2).
- **Токен дозора** в сессии разработки может не быть — тогда проверка выкатки только по открытым адресам и GitHub `postdeploy`;
  сказать об этом пользователю.
