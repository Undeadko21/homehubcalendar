# HomeHubCalendar для KOReader

Плагин `0.3.0` для Kindle Basic 2024 (KT6) с KOReader `2026.07.1`. Горизонтально слева видна неделя, справа — события выбранного дня. «Повернуть» переключает на подробный день в вертикальном виде и обратно. Недавно загруженные недели доступны без Wi-Fi с указанием времени сводки.

## Установка

1. Скопируйте папку `homehubcalendar.koplugin` целиком в `koreader/plugins/` на читалке. Должен получиться путь `koreader/plugins/homehubcalendar.koplugin/main.lua`.
2. Полностью перезапустите KOReader. В меню **Инструменты** откройте **Домашний календарь → Подключить календарь**.
3. В HomeHubCalendar откройте **Настройки → Связь вне дома**. Включите «Читать с сервера» для виджетов и скопируйте код подключения из раздела «Облако Яндекс.Диска». Вставьте код в диалог на читалке. Если у вас уже есть токен виджета, его тоже можно ввести.
4. Нажмите **Обновить**. Нажмите день недели слева, чтобы увидеть его события. Стрелки и горизонтальный жест по расписанию листают недели в горизонтальном режиме и дни в вертикальном. Длинное расписание прокручивается. «Сегодня» возвращает к текущей дате.

Из кода подключения плагин берёт только токен виджета. Токен и последняя сводка сохраняются в файле `settings/homehubcalendar.lua` внутри каталога данных KOReader. При смене токена старая сводка очищается.

Для ввода через USB положите код или токен в обычный текстовый файл `homehubcalendar-connect.txt` внутри папки плагина. На читалке выберите **Домашний календарь → Импортировать код с USB**. После сохранения подключения плагин удалит этот файл.

## Быстрое меню

В менеджере жестов KOReader выберите жест и добавьте действие **Общие → Календарь**. Чтобы этим же жестом открывать другие действия, добавьте их и включите **Показывать как быстрое меню**. Жест можно назначить отдельно в списке файлов и во время чтения. Если открыть календарь поверх книги, кнопка **К книге** вернёт на ту же страницу и восстановит ориентацию чтения.

Для HTTPS используется LuaSec из KOReader. В `isrg-roots.pem` находятся публичные корневые сертификаты [ISRG Root X1 и X2](https://letsencrypt.org/certificates/). Плагин проверяет цепочку и имя сервера до передачи токена.
