# HomeHubCalendar

Пиши по-русски. Начни с `docs/dev/followups.md` и прочитай `CLAUDE.md` как справочник по проекту, его архитектуре и правилам релиза. Для Codex используй роли из `.codex/agents/`. Перед изменением проверь `docs/dev/decisions.md` и `docs/dev/pitfalls.md`.

## Агенты Codex

| Роль | Когда подключать |
| --- | --- |
| `architect` | Перед крупной функцией, изменением форматов данных или API. |
| `executor` | Для отдельной части задачи в выделенном рабочем дереве. Передай границы изменений и список файлов. |
| `reviewer` | Для изменений крупнее мелкой правки. Для крупных изменений запусти два параллельных ревью с фокусами «данные и время» и «безопасность и прод». |
| `ui-tester` | Когда меняется интерфейс. Передай экраны и сценарии для проверки на демо-данных. |
| `apps-checker` | Когда меняются Android, iPhone, Mac или серверные форматы, от которых они зависят. |

Каждому агенту передавай цель, относительные пути и базовую ветку или диапазон коммитов, если он нужен. Главный агент объединяет результаты и отвечает за итоговую проверку.

## Релиз

Изменения в `main` автоматически попадают на домашний сервер. Работай в отдельной ветке и перед слиянием запусти `./deploy/check.sh`. Для правок Swift используй pull request со сборкой в CI. Секреты и данные семьи держи вне репозитория, логов и ответов.
