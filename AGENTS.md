# HomeHubCalendar

Работаем по-русски. Это семейный календарь на FastAPI, SQLite и Vue 3 с приложениями Android, iPhone и Mac и навыком Алисы.

Начинай работу с `docs/dev/followups.md`. Прочитай правила проекта в `CLAUDE.md`, затем нужные разделы `docs/dev/decisions.md` и `docs/dev/pitfalls.md`. Перед добавлением возможности сверься с `docs/dev/features.md`.

## Разработка и выпуск

- Основная рабочая ветка проекта — `main` репозитория `Undeadko21/homehubcalendar`. Пуш и слияние в неё запускают автоматическую выкладку на домашний Proxmox. Перед публикацией выполни `set -o pipefail; ./deploy/check.sh` и дождись успешного результата. Для изменений Swift соблюдай порядок выпуска через PR и GitHub Actions из `CLAUDE.md`.
- Миграции SQLite добавляй в конец `MIGRATIONS`. Сохраняй совместимость старых клиентов с API, снимками, кодом подключения, облачными командами и виджетами.
- При изменении `deploy/update.sh` сохраняй байтовое смещение строки `git reset`. Соблюдай правила подписи и версий приложений, пересборки пакета Алисы и ведения журнала изменений из `CLAUDE.md`.
- Храни секреты вне репозитория, логов и ответов. Для локальной проверки интерфейса используй демо-данные. Порядок контроля после выкладки описан в `CLAUDE.md`.

## Агенты Codex

Определения ролей лежат в `.codex/agents/`. Подробные чек-листы находятся в одноимённых файлах `.claude/agents/`.

- `architect` готовит план крупной функции, включая данные, совместимость и проверки.
- `executor` реализует выделенную часть задачи в отдельном worktree. При делегировании укажи ветку, каталог и допустимые файлы.
- `reviewer` проводит независимое ревью перед выпуском. Для крупной правки делегируй два ревью с фокусами «данные и время» и «безопасность и прод».
- `ui-tester` проверяет изменённые экраны и состояния на разных размерах и в обеих темах.
- `apps-checker` проверяет изменения нативных клиентов и затронутые контракты сервера, версии и CI.
